# Новостной Telegram-бот: e-commerce · ритейл · SaaS · технологии · AI

Бот собирает свежие новости российского рынка из RSS-лент, отбирает релевантные и переупаковывает
каждую через Claude в формат:

> **Что случилось.** Суть новости в 1–2 предложениях, только факты.
>
> **Какие открываются возможности:**
> 1. Конкретная возможность. *Аргумент, почему она следует из новости.*
> 2. …

Негативные новости (штрафы, блокировки, уход с рынка, сбои) не замалчиваются: факты остаются
честными, а блок возможностей показывает, кто и как может на этом выиграть.

## Как это работает

```
RSS-ленты ──> фильтр по ключевым словам ──> дедупликация (SQLite) ──> Claude ──> Telegram
 (sources.py)      (sources.py)                 (storage.py)        (rewriter.py)  (telegram_bot.py)
```

1. `fetcher.py` параллельно скачивает ленты из `sources.py`, отсекает статьи старше `MAX_ARTICLE_AGE_HOURS`
   и те, где нет ни одного тематического ключевого слова.
2. `storage.py` запоминает каждую статью, чтобы не публиковать её дважды.
3. `rewriter.py` отправляет новость в Claude со структурированным ответом (`relevant`, `topic`, `headline`,
   `summary`, `opportunities[]`). Модель заодно отсеивает нерелевантное и дубли уже вышедших тем.
4. `telegram_bot.py` публикует посты в канал и/или подписчикам и обрабатывает команды.

## Запуск

### 1. Создайте бота
В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
Если хотите публиковать в канал, добавьте бота в канал администратором с правом публикации.

### 2. Настройте окружение
```bash
cd news-bot
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY, при желании TELEGRAM_CHANNEL_ID
```

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather | обязательна |
| `ANTHROPIC_API_KEY` | ключ Anthropic | обязательна |
| `TELEGRAM_CHANNEL_ID` | `@канал` или `-100…` для автопубликации | пусто (только подписчики) |
| `DIGEST_INTERVAL_HOURS` | период автовыпуска, часов; `0` — выключить | `6` |
| `MAX_ITEMS_PER_DIGEST` | новостей в одном выпуске | `5` |
| `MAX_ARTICLE_AGE_HOURS` | брать новости не старше, часов | `36` |
| `CLAUDE_MODEL` | модель | `claude-opus-5-5` |
| `ADMIN_IDS` | Telegram id админов (команда `/run`) | пусто |

### 3а. Локально
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

### 3б. Docker
```bash
docker compose up -d --build
docker compose logs -f
```

### Другие режимы
```bash
python -m bot.main --once                 # один выпуск и выход — удобно по cron
python -m bot.main --demo tests/fixtures/sample.xml   # прогнать локальный RSS через модель, Telegram не нужен
```

## Команды бота

| Команда | Действие |
|---|---|
| `/news` | собрать и прислать свежий выпуск сейчас |
| `/subscribe` / `/unsubscribe` | подписка на автовыпуски в личку или группу |
| `/status` | когда был последний сбор и сколько вышло |
| `/run` | (админы) принудительно запустить плановый выпуск в канал и подписчикам |
| `/help` | справка |

## Как настроить под себя

- **Источники** — список `SOURCES` в `bot/sources.py`. Добавьте любую RSS-ленту: имя, URL, тема.
  Недоступная лента просто пишется в лог и пропускается.
- **Ключевые слова** первичного фильтра — `KEYWORDS` там же. Это грубое сито, окончательное решение
  принимает модель.
- **Тон и структура постов** — `SYSTEM_PROMPT` и схема `RewrittenNews` в `bot/rewriter.py`.
  Например, чтобы было 3–4 возможности вместо 2–3, поменяйте описание поля `opportunities` и промпт.
- **Оформление сообщения** — `format_news` в `bot/formatter.py`.

## Стоимость
На одну статью уходит примерно 1 000–1 500 входных и 300–500 выходных токенов. Системный промпт
кэшируется. При 25 кандидатах за выпуск и 4 выпусках в день это порядка 100 вызовов в сутки.
Для экономии можно поставить `CLAUDE_MODEL=claude-sonnet-5-5` или `claude-haiku-5-5`.

Если классификаторы безопасности Anthropic отклонят запрос, включён серверный fallback
(`fallbacks="default"`): запрос автоматически повторяется на запасной модели.
