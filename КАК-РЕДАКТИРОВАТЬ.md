# Обучение Дживио — как пользоваться и наполнять

## Как открыть
Откройте файл **`index.html`** двойным щелчком — обучение запустится в браузере.
Всё работает офлайн (шрифты, иконки, логотип уже внутри). Интернет нужен только если
вставляете видео с YouTube / Vimeo.

## Структура папки
- `index.html` — точка входа, открывать этот файл.
- `content.js` — **единственный файл, который вы редактируете.** Весь текст обучения здесь.
- `styles.css`, `app.js` — оформление и логика (трогать не нужно).
- `assets/` — логотипы, иконки продуктов, шрифты Дживио.
- `videos/` — сюда кладите свои видеофайлы (.mp4).

## Как добавить / изменить процесс
Откройте `content.js` в любом текстовом редакторе. Каждый процесс — это блок:

```js
{
  id: 'moy-process',                         // латиницей, уникально
  title: 'Название процесса',
  summary: 'Короткое описание одной строкой',
  duration: '5 мин',
  tags: ['Wildberries', 'Ozon'],
  video: { type: 'youtube', src: 'ID_видео' },   // см. ниже
  clientProcess: {
    pain: 'Как клиент делает это сейчас, вручную',
    steps: ['Шаг 1', 'Шаг 2', 'Шаг 3'],
  },
  djivioSolution: {
    intro: 'Что делает Дживио',
    steps: [
      { title: 'Действие', desc: 'Пояснение' },
    ],
    result: 'Итоговая выгода для клиента',
  },
  apply: ['Что сделать прямо сейчас — шаг 1', 'шаг 2'],  // интерактивный чек-лист
}
```

## Как привязать видео (обязательно для каждого процесса)
Внутри процесса меняете строку `video`:

| Источник | Как записать |
|---|---|
| YouTube | `video: { type: 'youtube', src: 'dQw4w9WgXcQ' }` — ID из ссылки |
| Vimeo | `video: { type: 'vimeo', src: '76979871' }` |
| Свой файл | `video: { type: 'file', src: 'videos/moe-video.mp4' }` |
| Пока нет | `video: { type: 'none' }` — покажется заглушка «видео скоро» |

## Порядок изучения
У каждого направления есть поле `order` — это его номер в рекомендуемом пути
(0 — Настройка, 1 — Ценообразование, 2 — Реклама и т.д.). Порядок на главной
(дорожная карта, номера на плитках и в меню) строится по этому числу — поменяете
`order`, поменяется и последовательность.

## Как открыть новое направление
У направлений (Логистика, Ценообразование и т.д.) стоит `status: 'soon'`.
Поменяйте на `status: 'ready'` и добавьте процессы в массив `processes` — раздел станет активным.

## Прогресс
Пройденные процессы и отмеченные шаги сохраняются в браузере автоматически.
